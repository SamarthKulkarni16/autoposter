# 2026-08-31 — Autoposter: Pinterest fixed & proven; Facebook advanced

## PINTEREST — DONE & PROVEN (the urgent endless-loop fix)
- ROOT CAUSE found & fixed: the "endless title-disabled loop" was NOT automation
  detection. Playwright's bundled Chromium on this ARM64 Linux has NO H.264
  decoder, so Pinterest's CLIENT-SIDE validator rejected every H.264 MP4
  ("not encoded in H.264/H.265") and never enabled the Title field → the
  bot's 180s retry loop on the disabled title field.
- FIX: launch Canonical `chromium` SNAP (has H.264) for PLATFORMS_NEEDING_H264 =
  {pinterest, facebook} via `engine.open_account()` executable_path. Same
  user-data-dir profiles carry over.
- VERIFIED: `drive_platform.sh pinterest hi` → status: posted, twice, incl. a
  final reconfirm after the commit. Committed as 7181834.
